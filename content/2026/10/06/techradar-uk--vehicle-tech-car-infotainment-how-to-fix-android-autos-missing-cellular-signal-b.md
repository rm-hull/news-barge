* **Android Auto has, for weeks, had a bug that causes the cellular signal icon to disappear for some users**
* **A few days ago, Google acknowledged the issue and said a fix would be rolling out**
* **The stable version of Android Auto 17.8 is now available and appears to fix this bug**

Usually, software bugs are fixed quite quickly, but for weeks now, some Android Auto users have been experiencing a frustrating glitch that causes their phone’s cellular signal icon to disappear from the Android Auto display.

This hasn’t happened to every Android Auto user, and for some users, it’s been an intermittent bug, with the icon sometimes present and sometimes disappearing. But it’s annoying enough and widespread enough that Google has officially commented on it.

As spotted by 9to5Google, a representative for the company posted on Reddit that: “We’re aware of reports about the missing cellular signal, and we’re actually currently rolling out a fix that should hopefully address this issue! The fix isn’t widely available yet, though, so it may take some time to reach your device – if you want to receive it sooner, though, you can enroll in the Android Auto beta.”

Thankfully, it seems you no longer need to enroll in the beta to get the issue fixed, as many users report that Android Auto 17.8 addresses the problem, and the stable version of this OS package is now rolling out.

![Android Auto dashboard](https://cdn.mos.cms.futurecdn.net/ivUcCPnNPy9txnz6C5r45Y-1200-80.jpg)

## How to fix this Android Auto bug

So, if you’re experiencing this bug, you should definitely download the latest version of Android Auto. To do so, just head to the Google Play Store on your phone, type ‘Android Auto’ into the search bar, and hit the update button on it if one is present.

If there’s no update available, your phone may have already automatically downloaded version 17.8, but to check which version you’re running, head to Settings > Apps (or Apps & notifications). Then, just scroll down to Android Auto, tap on it, and the version number should be at the bottom of this screen. Alternatively, you should be able to see the version at the bottom of the settings screen inside the Android Auto app.

If you’re running version 17.8, then this should fix the issue, but if you’re still experiencing the bug, it’s worth clearing Android Auto’s cache. To do this, head to Settings > Apps > Android Auto again, and this time tap ‘Storage,’ followed by ‘Clear cache.’
