A rare, prototype copy of *Pokémon Red* for the Nintendo Game Boy, originally released back in 1998, is on sale at auction, with a single bid of $25,000 currently registered so far. This prototype, spotted by*Retro Dodo*, is "incredibly rare" and features 32KB of readable data. According to the Goldin auction page, the cartridge has been authenticated by specialists at PSA, who examined the card. According to them, while a "complete data read" wasn't possible, the first 32KB of data was, a "technically unique" result. The PSA notes, however, that the game data is otherwise "completely identical" to the U.S. release version of the game, with PSA "expressing confidence" that the rest of the data, if it were readable, would match.

The PSA report does note two changes to the ROM's header data that don't affect the game data. According to PSA, "the difference is at offset 0x014C, which denotes the Mask ROM version and is incorrectly set to 55 when it should be 00. This has the effect of changing offset 0x014D, which is a calculated header checksum, to CB instead of 20."

This prototype development cartridge has a sticker reading DMB-MBC-16M-FLASH, with a part number DMG-(F)KGDB-01. DMB likely refers to *Dot Matrix Game*, the original internal codename for the Game Boy, while MBC likely means Memory Bank Controller, a custom chip that allowed games to use more than the Game Boy's 32KB ROM limit. 16M likely refers to a 16 megabit limit of flash-writable memory.* Retro Dodo* notes that the cartridge is longer than a standard Game Boy cartridge, too.

The auction notes that this uses a "previously undocumented" development board, although the DMG-(F)KGDB-01 part number has been seen before. The Rare Gaming Dump wiki, for instance, lists the same part number for a development cartridge from 2000. It, too, had a 16 megabit Sharp flash chip, with U1 FLASH MEMORY printed on the board. Close-up views from the Goldin auction page show an almost identical design, although the wiki entry shows a slightly different DMG-MBC3-16M-FLASH cartridge sticker.

*Pokémon Red* is a gaming classic that helped kickstart the global*Pokémon* franchise in the 1990s, along with*Green* and*Blue*. Combined with* Blue*,* Pokémon Red* is reported to have sold more than 31 million copies. There are several days left to go on this auction, so while the single bidder may secure this piece of gaming history for $25,000, it may sell for an even higher price before the auction process ends.
