![Electronics hobbyist converts a $120 DDR5 SODIMM kit into a $1000 desktop kit ](https://cdn.mos.cms.futurecdn.net/MdjnzhyLexjj7qghWQJu55-1920-80.jpg)

What if you could buy a cheap used DDR5 SODIMM (laptop memory) kit and transform it into a super-fast DDR5 desktop kit? That’s what electronics hobbyist Blighted Agent recently did when they succeeded in converting a SK hynix 2x 16GB DDR5-5600 SODIMM kit they got from Facebook Marketplace for $120 into a 2x 16GB DDR5-7800 desktop kit, claimed to be worth around $1,000. They also had to buy some blank DDR5 desktop memory PCBs from AliExpress for around $16 each, and a set of heatsinks for around $18.

![I Turned Laptop DDR5 in Desktop DDR5 and then Overclocked It - YouTube](https://img.youtube.com/vi/bpT5CdOBNDU/maxresdefault.jpg)

In the above video, our hero says they bought the donor laptop 2x 16GB DDR5-5600 sticks for just $120, which is a bargain. With extra bits and pieces from AliExpress (desktop DDR5 PCBs, etc.), the total bill of materials came to $175. Blighted Agent comments that the SODIMMs used what he believed to be SK hynix A-die modules, which are the same as the ICs used in expensive desktop DDR5 modules like the G.Skill Trident Royal line.

The process began with taking the memory ICs from the donor modules using a hot air station. Then they were cleaned and had 0.45mm leaded solder balls added, using a DDR5 stencil, reballing jig, and hot air. Next, the blank desktop DDR5 PCBs were prepared. A little solder was added to the plethora of BGA connectors to be ready for the memory chips to connect to.

The old DDR5 ICs and the new desktop modules could now be mated, using flux, the preheater, hot air, and watching and prodding carefully with a dental pick. Blighted Agent’s experience lets him know when the BGA chips have successfully mated with the PCB. You can eyeball when they pop precisely into place due to surface tension, and offer up a modicum of resistance to pick prodding.

Finally, the enthusiast added the SPD chip and BIOS chip from the SODIMMs to the new desktop DIMMs. These new desktop DIMMs were quickly tested in a PC before they were finished off with carefully applied thermal pads and the fancy-looking heatsinks.

Blighted Agent felt lucky that there were no issues with the newly created desktop modules. There’s a lot of intricate things that can go wrong during such a process. The initial boot verification showed them recognized in his Asus ROG Maximus Z790 Apex Encore motherboard as two “SK hynix 16,384MB 5600MHz” modules, which was correct. Some tuning resulted in rock-steady performance at DDR5-7800 CL38 and 1.40V. This was verified by stress testing for 90 minutes, which the enthusiast reckons was ample for a gaming PC. It is very likely a better result than using those mechanical SODIMM-to-DIMM converters you can buy, which can be problematic.

Blighted Agent seems to specialize in BGA soldering work, and has also successfully upgraded several graphics cards with double the VRAM. Though videos like this are edited to be brief, and they make the process look easy, the TechTuber admits there is a lot that can go wrong during this kind of rework. Moreover, with RAM modules, they lack the testing equipment to locate an issue with any particular IC on the PCB. So, if this module didn’t work, they might have ended up in a world of pain, not knowing which memory chip had an issue due to either an internal fault or a BGA soldering glitch.

Looking around at used DDR5 SODIMMs, it looks like Blighted Agent was very lucky to get a used working 32GB kit for $120. I just checked eBay U.S., and the best deal there was $320. Meanwhile, the best price for a new 32GB DDR5-6000 kit seems to be $449 at the time of writing.

We reported on Russian enthusiast VIK-on succeeding in a similar project earlier this year, but all their costing was in Rubles, and they went the extra mile in flashing custom firmware so the remade modules would be auto-detected with 6400 MT/s XMP support on most motherboards. In late 2026, DDR5 RAM continues to be too expensive.
