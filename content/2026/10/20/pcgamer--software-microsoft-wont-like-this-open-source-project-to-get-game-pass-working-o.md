It wasn't long ago that Linux gaming was considered fairly niche—but given that Windows 11 is unpopular with many, it seems that not a day goes by without something regarding the switch to Linux hitting my newsfeed. Not to mention the continuing updates to Valve's Arch-based SteamOS.

Now my attention has been drawn to the Xodus Nexus, an experimental open-source project that aims to allow Linux and SteamOS users to access PC Game Pass. This includes the ability to browse, install, and launch games via a *very* familiar interface, complete with cloud save support.

That's for supported games only, of course, but the GitHub page has a big long list of them. From Gears of War: E-Day, to Minecraft for Windows, to Halo: Campaign Evolved, there sure are some big hitters that are already supported by the open-source platform.

The readme describes the project as "An Xbox-inspired launcher built on Xodus, using our patched Nexus backend and Nexus runtime. Browse the store, install games you own or can access through a subscription, and play with one shared runtime."

The whole system seems to be in an experimental test phase at the moment, and the controller navigation looks to be a work in progress, too. However, games can be added to Steam as non-Steam-game shortcuts, and Xbox achievements have been added in the latest update, alongside many other features.

> 🚨 PC GAME PASS is now being made playable on Linux and SteamOS through an unofficial open-source project called Xodus Nexus. 👀 • Xodus Nexus can browse, install and launch supported Microsoft Store / Game Pass PC games on Linux • Uses a patched Xodus backend + Proton-based Nexus runtime • Xbox sign-in and cloud saves work for supported games • Forza Horizon 6, Gears of War: E-Day, Sea of Thieves, Avowed and others are listed as playable • Games can be added directly to Steam as Non-Steam shortcuts • New v0.3.8 adds Xbox achievements, playtime and last-activity tracking • Controller navigation and Steam Game Mode integration are actively improving • FACT: this is an independent unofficial project, NOT Microsoft, Valve or upstream Xodus • FACT: compatibility remains game-dependent and Steam Deck support is still experimental • SPECULATION: if development holds up, this could remove one of SteamOS/Linux gaming’s biggest remaining limitations Game Pass library has been a massive missing piece for SteamOS. Huge credit to domsvoboda and everyone testing it, but this is still early software so I wouldn’t treat Game Pass on Linux as completely solved yet.October 19, 2026

All of which makes me think that Microsoft may be a little... miffed when it reads this project's goals. Not to mention the UI similarities. I have no idea if it's possible for MS to detect if this third-party system is in use, or if the software giant will ever do anything to try and scupper it. Still, use at you own risk is probably the main messaging here.

You do at least need a valid Microsoft account, and of course, an active Game Pass subscription to use it. Or licenses for the games themselves, so no money is changing hands with the wrong parties. Regardless, I can't but help admire the moxie of the open source community. If it doesn't exist yet, someone will try and build it. Carry on.
