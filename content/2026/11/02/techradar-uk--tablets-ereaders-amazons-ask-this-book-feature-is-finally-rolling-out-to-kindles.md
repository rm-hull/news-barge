* **Amazon's 'Ask this book' feature is now rolling out to Kindles**
* **It's part of software version 5.20.2**
* **So far, users have only reported this landing on 2026 models, and it might currently be US-exclusive**

Amazon launched ‘Ask this book’ almost a year ago now, with this AI-powered tool allowing you to ask questions about what you’re reading. However, it was initially only available for the iOS Kindle app, and only in the US.

Now, though, that availability is widening — at least a little. As spotted by some Reddit users and The eBook Reader, ‘Ask this book’ has started rolling out to certain Kindle models, including the Kindle Colorsoft 2026 and the Kindle Paperwhite 2026. It’s likely that the other 2026 Kindles will also receive this update, though that hasn’t been confirmed.

Indeed, Amazon itself has so far said very little about this rollout. The feature is part of software version 5.20.2, but this doesn’t yet have any release notes, or any confirmation beyond user reports of which models ‘Ask this book’ will actually work with.

![The Ask this book feature on a Kindle](https://cdn.mos.cms.futurecdn.net/kUwMWKCVLgZzqWZiZeMtvV-729-80.jpg)

## Unclear availability

So, for now, there’s a question mark over whether the feature is coming to previous Kindle generations — I can say that my Kindle Colorsoft Signature Edition 2024 does not yet have the update. But then it’s a UK model, and previously, the feature had only been available in the US — so it also remains to be seen whether other regions will get it.

For now, if you’re curious, you’ll seemingly have to wait and see whether your Kindle gets the update pushed to it — there is no way to force the update currently. The rollout might happen in stages, though, so even if you don’t have it yet, you may still get it. Just make sure Wi-Fi is on so your Kindle can update.

As for the ‘Ask this book’ feature itself, it’s potentially very useful, letting you, for example, ask about the plot or characters of a supported book and receive information based on where you’re up to in it — or for the whole book if you don’t mind spoilers.

As with most AI features, though, it’s also controversial, with Reddit comments about its original launch including “I hate it,” and “this feature is so invasive.” So it’s certainly not for everyone.
