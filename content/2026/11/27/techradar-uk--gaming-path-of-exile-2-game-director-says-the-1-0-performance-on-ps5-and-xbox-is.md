* ***Path of Exile 2*game director Jonathan Rogers says the 1.0 launch "should be performing quite a lot better on the consoles"**
* **Rogers says CPU and memory improvements has made the performance "better" and it will run at 60FPS on PS5 and Xbox**
* **The file size has also been reduced significanty after some "asset compression"**

*Path of Exile 2* is set to leave early access soon, and its players can expect improved performance and memory size on PS5, Xbox Series S, and Xbox Series X.

That's according to game director Jonathan Rogers, who confirmed in a group interview with TechRadar Gaming that the 1.0 launch next month has been updated for consoles and will perform "a lot better."

"The performance in 1.0 is better than before because CPU improvements are good for any platform, especially consoles,” Rogers said.

The game director explained that memory was a big issue on consoles, and so Grinding Gear Games made it a priority to reduce the file size, which also aided smoother performance.

"We had some memory issues on consoles before, and we've also done some asset compression to make the game quite a lot smaller on consoles," he said, adding that the file size was "like 140GB, and now it's like 80GB."

Rogers added, "Overall, it should be performing quite a lot better on the consoles as well. On the PS5 Pro in particular, what you'll get basically is just high resolution, and the game will just run nicer."

As for frame rate, the director confirmed a target rate of 60FPS as the team "always target 60 [frames-per-second]" because "I hate 30."
