A residential property could soon become a HMO for six people, under new plans.

The proposal would see a property on Elwick Road in Hartlepool converted into a house in multiple occupation (HMO) for up to six people.

A certificate of lawfulness application has been submitted to Hartlepool Borough Council, seeking confirmation that the change from a Class C3 dwelling to a Class C4 small HMO is permitted under planning regulations.

No external changes are planned, with scheme including one shared kitchen and living room, with a single entrance serving all residents.

A planning statement supporting the application said: "The operational model and physical layout are consistent with one Class C4 HMO.

"The description identifies the maximum number of residents, rather than referring only to the number of bedrooms, so there can be no ambiguity over the use for which certification is sought."

The proposed layout does include six individual bedrooms, each for a single occupant.

A rear yard would be kept for outdoor use and bin storage.

Each bedroom would feature en-suite washing facilities, but the planning statement argues that this does not make them self-contained units, as they lack cooking areas.

The statement said: "They do not contain independent cooking facilities and cannot function as separate homes."

A decision on the application is expected later this year.
