- **Microsoft has summarized its campaign to fix Windows 11 so far**
- **The company also let us know what work is coming, including making the OS run better with 8GB of RAM**
- **That should have been the case from the start, though – and there's a missing piece of the puzzle to address as highlighted by Windows 11 users**

Microsoft has made it clear that it's working to ensure that Windows 11 runs better on 8GB of system memory, as well as letting us know about other elements of the OS the company is going to fix as 2026 rolls on.

This was part of a blog post which is an update on the progress made with the campaign to fix Windows 11 that kicked off in March, summarizing all the work Microsoft has done – and there's been a lot of that, without a doubt. (I recently picked out the most important changes so far, if you're interested).

Microsoft also highlighted four new areas it's going to deal with during the rest of the year, and one of those is Windows 11's RAM usage.

Microsoft wrote: "Memory optimization for 8GB and above. Reducing Windows memory footprint to deliver a fast and responsive Windows experience across the PCs customers use every day."

As well as a promise, this is an acknowledgement of the RAM crisis, which is preventing people from upgrading their memory, but more to the point, it's forcing laptop makers to go backwards in some respects, dropping RAM loadouts to 8GB for some models. (Whereas previously we'd been moving noticeably towards 16GB as a baseline).

As to what else Microsoft has on its fixing checklist, that includes making Windows 11's setup a faster and more efficient experience, as well as a better setup for families (including parental controls being more readily accessible). Finally, Microsoft says voice functionality is also being worked on, to make "voice more natural and fluid to interact across the apps you use every day".

## Analysis: it's about time really – and there's another issue that needs to be addressed, too

 ![Windows 11 on a laptop](https://cdn.mos.cms.futurecdn.net/vUENLgpmE9SAJMUqFSigSF.jpg) 


Microsoft talked about RAM optimization and "lowering the baseline memory footprint for Windows" back when the campaign to fix its OS first began. So really, this is just a reassurance that this work is underway and should be arriving before the end of the year, and that it's specifically focused on ensuring 8GB is an acceptable amount of memory for running Windows 11.

As noted, there's more pressure around this now thanks to the RAM crisis getting worse, and laptop makers looking to produce more 8GB models in a cost-saving effort. On top of that, there's the embarrassment of the MacBook Neo showing that Apple can do 8GB, and do it well, with macOS.

Really, though, Windows 11 should've been better optimized for performance right from the start – or at least after the first year or two of its existence. Why has it taken a RAM apocalypse, a huge anti-Windows backlash (prompted by AI), and the launch of a rival budget-friendly MacBook to prompt Microsoft to get off its system performance laurels and actually do something serious about how well its desktop operating system runs with a leaner amount of memory? Remember, Windows 11 is supposed to work with 4GB (as a minimum), so 8GB should not be as much of an issue as it has always been.

Obviously it's good that this is now happening, and more broadly, I'm still pleased Microsoft is addressing a whole bunch of problems with its drive to fix Windows 11. There's one piece of the puzzle omitted here, though, based on some of the feedback which has come through on social media after Microsoft's blog post update.

While Redditor 'Melchett_General' acknowledges that "some of this is very nice" when it comes to Microsoft's summarized fixes, they point out some missing bits, one of which is notably echoed elsewhere – namely the recent LG monitor controversy.

The Redditor complains: "How on earth Windows got to the state where any manufacturer that makes a device can have software 'companion' applications installed silently on a user's device without the wider internet throwing a collective fit and having Microsoft permanently change course I don't know."

In case you missed it, this refers to LG serving Windows 11 users a McAfee pop-up via its monitor software, and it's a story with some degree of nuance. Microsoft did immediately take action to get LG to banish that McAfee advert, which popped up via the LG monitor app in Windows 11, but as I discussed previously, a wider problem remains here.

This is the issue that the LG application is piped through to the operating system via Windows Update without the user's knowledge, happening automatically when the LG monitor is connected to the system.

In other words, the McAfee pop-up might have been quickly dealt with, but it's still possible for hardware makers to get Windows Update to pipe through a tool for their device.

 ![An LG Ultragear GX9 on a desk](https://cdn.mos.cms.futurecdn.net/sV3QTWQVuKkwzxpG326DEH.jpg) 


As the Redditor elaborates: "What this seems to mean is that a 3rd party can install what they like whenever they like on your internet connected Windows computer and there's no effective way to stop it. (Aside from GP [Group Policy] edits or registry changes).

"This needs to be addressed, and there needs to be a mechanism to allow people to easily prevent this from happening."

I couldn't agree more. There should be no scenario where software is automatically installed in this way, even if the device maker might argue that the app is very much for the user's benefit. At the very least, there should be a dialog box announcing what's happening, and giving you the ability to choose not to install whatever application the hardware maker wants to put on your PC.

Notably, I haven't heard anything from Microsoft addressing this broader issue. Never mind the symptom (the McAfee pop-up), tackle the root cause of the issue (the ability for a piece of connected hardware to whisk its own software off the internet with no say from the user).

Microsoft is clearly serious about fixing everything that's wrong with Windows 11, I don't dispute that – but I find it odd that nothing has been said that directly addresses this pain point. Hopefully that won't be the case for much longer – we need some more transparency with Windows Update in this regard.
