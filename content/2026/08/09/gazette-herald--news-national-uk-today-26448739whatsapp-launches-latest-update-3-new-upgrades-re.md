WhatsApp has launched a new update bringing fresh features to group chats.

The latest update features three changes/upgrades, all designed to enhance users' group chat experience.

A WhatsApp spokesperson said: "Earlier this year, we upgraded group chats with the launch of group message history, member tags and event reminders.

"We're continuing that momentum with smarter polls, @all mentions, and faster group chat creation.


"With more than 100 million people in the U.S. on WhatsApp, and over 3 billion people globally, there's no better place for your group chats."

## What users can expect from the new WhatsApp update

The messaging app now allows users to tag everyone in a chat using ‘@all,’ create new groups from existing groups, and make smarter decisions with improved polls.

### New @all feature

The new ‘@all’ feature notifies every member of a group when an important, time-sensitive message is sent.

It means users no longer need to tag individuals one by one or worry about messages being missed in busy conversations.

The feature is available to all users in groups with 32 members or fewer.

In larger groups, only admins can use it.


### Improved polls

WhatsApp has also improved polls to support group decision-making with three new functions.

Users can now set an end time for voting, hide voter names to encourage honest feedback, and edit poll questions within 15 minutes.

### Create group chats from existing groups

The update also makes it easier to start a new chat with specific members of an existing group, allowing users to quickly create side conversations without cluttering the main discussion.

WhatsApp said these features are ideal for planning smaller events, coordinating last-minute changes, or discussing topics in more detail with a select group.

## How to reserve a WhatsApp username

WhatsApp also recently announced it was launching usernames.

Users can now reserve a username, which they will be able to use later this year when the feature officially goes live.

To reserve a WhatsApp username, go to 'Settings', 'Account', then 'Username'.
